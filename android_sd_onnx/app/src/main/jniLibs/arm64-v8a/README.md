# Native Libraries

Place the required ARM64-v8a native libraries here.

You need:
1. ONNX Runtime native libraries (including QNN Execution Provider).
2. Qualcomm QNN libraries (e.g., `libQnnHtp.so`, etc.).

These files should be placed directly in this directory (`android_sd_onnx/app/src/main/jniLibs/arm64-v8a/`).
